# SOMA - Space Operations Medical Assistant

SOMA (Space Operations Medical Assistant) is an offline, on-device voice assistant that enables astronauts to monitor and log health data in hands-free mode and visually during deep space missions without Earth communications. Built for the 2026 NASA International Space Apps Challenge.

> Note: Fixing issues with large files 25mb not being accepted by github.

## INSTRUCTIONS:

This Demo is for Linux only.

1. Download all three .zip files and extract SOMA-split.zip, this will auto unzip all zip files and present you with SOMAv1 folder.

2. Download LLM model before use, put it in SOMAv1/models folder:
https://huggingface.co/unsloth/Qwen3.5-4B-GGUF/blob/main/Qwen3.5-4B-Q3_K_M.gguf

3. Download STT model before use, put it in SOMAv1/stt-models folder:
https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-base.en-q8_0.bin

4. Right click on start.sh and tick mark Allow executing file as program and then click Start.sh to run.

5. Local webpage will auto open or go to http://127.0.0.1:8080 in Chrome, Firefox web browser.

Youtube Demo: https://www.youtube.com/watch?v=GffKs_kmG94
