# SOMA-Space-Operations-Medical-Assistant
SOMA (Space Operations Medical Assistant) is an offline, on-device voice assistant that enables astronauts to monitor and log health data in hands-free mode and visually during deep space missions without Earth communications. Built for the 2026 NASA International Space Apps Challenge.

INSTRUCTIONS:
This Demo is not Linux only.
Download LLM model before use, put it in /models folder: https://huggingface.co/unsloth/Qwen3.5-4B-GGUF/blob/main/Qwen3.5-4B-Q3_K_M.gguf
Download STT model before use, put it in /stt-models folder: https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-base.en-q8_0.bin
Click Start.sh to run.
Navigate to displayed url in terminal or go to http://127.0.0.1:11434 in any web browser.

Youtube Demo: https://www.youtube.com/watch?v=GffKs_kmG94
